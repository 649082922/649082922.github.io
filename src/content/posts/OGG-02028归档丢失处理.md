4.登录数据库
dblogin USERID c##ggadm@C06U30ST_ogg PASSWORD Cmb#2020

5.如果是ds库，先登录源库再登录ds库
miningdblogin USERID c##ggadm@C06U30ST_ogg PASSWORD Cmb#2020

6.取消注册
unregister extract EXTPDK10 database

7.从前时间点重新抽数，重新注册
alter extract EXTPDK10 begin now
register extract EXTPDK10 database container (PDKTRX05)

8.启动进程
start EXTPDK10

9.检查进程状态，等待同步
info all
