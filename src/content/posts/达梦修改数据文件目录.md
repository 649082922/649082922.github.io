1.关闭数据库服务，迁移数据目录路径
启停集群(方法备用)
启动数据库
启动主库实例:/dm8/bin/DmService_rural_01 start
启动备库实例:/dm8/bin/DmService_rural_02 start
启动主库守护:/dm8/bin/DmWatcherService_rural_01 start
启动备库守护:/dm8/bin/DmWatcherService_rural_02 start
启动主监视器:/dm8/bin/DmMonitorServiceDMMONITOR_rural_P start
启动备监视器:/dm8/bin/DmMonitorServiceDMMONITOR_rural_S start

停止数据库
关闭顺序：监控器、守护、实例
停止备监视器:/dm8/bin/DmMonitorServiceDMMONITOR_rural_S stop
停止主监视器:/dm8/bin/DmMonitorServiceDMMONITOR_rural_P stop
停止备库守护:/dm8/bin/DmWatcherService_rural_02 stop
停止主库守护:/dm8/bin/DmWatcherService_rural_01 stop
停止主库实例:/dm8/bin/DmService_rural_01 stop
停止备库实例:/dm8/bin/DmService_rural_02 stop

2.创建目标目录
mkdir /data2
chown -R dmdba.dinstall /data2
mv /data/dmdata  /data2/dmdata

3.修改dm.ini (将涉及的目录都修改)
vi /data/dmdata/DAMENG/dm.ini
#file location of dm.ctl
CTL_PATH        = /data2/dmdata/DAMENG/dm.ctl    #ctl file path
CTL_BAK_PATH    = /data2/dmdata/DAMENG/ctl_bak   #dm.ctl backup path
SYSTEM_PATH     = /data2/dmdata/DAMENG           #system path
CONFIG_PATH     = /data2/dmdata/DAMENG           #config path
TEMP_PATH       = /data2/dmdata/DAMENG           #temporary file path
BAK_PATH        = /data2/dmdata/DAMENG/bak       #backup file path
DFS_PATH        =                                #path of db_file in dfs

4.修改ctl文件
1.将ctl转为txt
./dmctlcvt  TYPE=1  SRC=/data2/dmdata/DAMENG/dm.ctl  DEST=/data2/dmdata/DAMENG/dmctl.txt
2.批量修改txt中的涉及目录的部分
3.将txt转回ctl
./dmctlcvt  TYPE=2  SRC=/data2/dmdata/DAMENG/dmctl.txt  DEST=/data2/dmdata/DAMENG/dm.ctl

5.修改服务
1.修改DmServiceXX
INI_PATH="/data2/dm218data/DAMENG/dm.ini"
2.修改数据目录dmwatcher.ini
vi /data/dmdata/DAMENG/dmwatcher.ini
[GRWC1]
INST_INI                 = /data/dmdata/DAMENG/dm.ini  #dm.ini 文件路径

数据库启动，验证主备情况

6.通过dmrman备份，恢复时指定 REUSE DMINI参数，即可自动修改dm.ini中的路径参数
./dmrman
backup database  '/data/dmdata/damengdb/dm.ini' backupset '/data/dmbak/20251217fullbak'
compressed level 1 parallel 4;
check backupset '/data/dmbak/20251217fullbak'
