1.脚本使用
#只支持最新版的达梦8、9
DMShellInstall-master 压缩包
装老版本需要删除（参数是拼接字符串，注释无效）：RLOG_POSTFIX_NAME=$rlog_postfix_name \

#支持2022.09.27版本达梦8
soft 压缩包

2.参数注意
-hn  demo `# 只写一个主机名，其他会加序号递增 node01,node02`
-iso n `# yum源已经配置好,设置n` \
-dbg y `# 报错信息调试,设置y`
-sp  demo `# 不用写特殊字符，会识别不了`

3.许可证注意
使用脚本跑完后不要直接按重启，先换dm.key,再y重启
#查看数据库版本
Select build_version from v$instance;
#数据库更新授权,检查
sp_load_lic_info();
select EXPIRED_DATE from V$LICEESE;

4.重启后手动拉起进程
启动数据库
启动主库实例:/dm8/bin/DmService_rural_01 start
启动备库实例:/dm8/bin/DmService_rural_02 start
启动主库守护:/dm8/bin/DmWatcherService_rural_01 start
启动备库守护:/dm8/bin/DmWatcherService_rural_02 start
启动主监视器:/dm8/bin/DmMonitorServiceDMMONITOR_rural_P start
启动备监视器:/dm8/bin/DmMonitorServiceDMMONITOR_rural_S start

停止数据库
关闭顺序：监控器、守护、实例
停止备监视器:/dm8/bin/DmMonitorServiceDMMONITOR_rural_S stop
停止主监视器:/dm8/bin/DmMonitorServiceDMMONITOR_rural_P stop
停止备库守护:/dm8/bin/DmWatcherService_rural_02 stop
停止主库守护:/dm8/bin/DmWatcherService_rural_01 stop
停止主库实例:/dm8/bin/DmService_rural_01 stop
停止备库实例:/dm8/bin/DmService_rural_02 stop
