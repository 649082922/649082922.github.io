========================================
安装方式
========================================

通用安装命令：
npx skills add <仓库地址>
npx skills add <仓库地址> --skill <skill名称>

Claude Code 插件方式：
claude plugin marketplace add <组织>/<仓库>
claude plugin install <插件名>@<marketplace名>

手动方式：
将 SKILL.md 内容复制到项目的 .claude/instructions.md 或 AGENTS.md 中
