1.安装前置软件
安装 Node.js 18 或更新版本环境（依赖软件，使用lts版本）
https://nodejs.org/en/download/
node --version && npm --version

报错：The installer has encountered an unexpected errorinstalling this package.
      This may indicate a problem withthis package. The error code is 2503.
解决方法：
以管理员身份打开命令提示符，输入命令 msiexec /package "完整MSI文件路径"进行安装

Windows 额外需安装 Git for Windows 方便使用base终端
https://git-scm.com/install/windows
git --version

2.使用Node.js 包管理器全局安装claude code
npm install -g @anthropic-ai/claude-code

@anthropic-ai可能国内网络会慢，需要梯子
https://github.com/anthropics/claude-code

#回退版本
npm install -g @anthropic-ai/claude-code@2.1.89
#卸载
npm uninstall -g @anthropic-ai/claude-code

3.安装Coding Plan软件管理器
# 进入命令行界面，执行如下运行 Coding Tool Helper
npx @z_ai/coding-helper

官网：https://docs.z.ai/devpack/extension/coding-tool-helper#method-2-global-install-for-frequent-use

4.对cc添加大模型
#手动修改配置文件 ~/.claude/settings.json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "GLM的API key",
    "ANTHROPIC_BASE_URL": "https://api.z.ai/api/anthropic",
    "API_TIMEOUT_MS": "3000000",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "glm-4.5-air",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-4.7",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-4.7"
  }
}

#国内网络不可以用，使用其他类型的大模型需要配置
#  "env": {

#    "HTTPS PROXY":"http://127.0.0.1:7890"

5.Windows修改Git环境变量
setx CLAUDE_CODE_GIT_BASH_PATH "E:\Program Files\Git\bin\bash.exe"

6.下载vscode
安装chinese
 按下“Ctrl+Shift+P”组合键以显示“命令面板”，然后键入“display”以筛选并显示“Configure Display Language”命令。
 按“Enter”，然后会按区域设置显示安装的语言列表，并突出显示当前语言设置。

安装claude code
 安装完成后，点击如下图中的右上角 Claude Code 图标，即进入 Claude Code 页面，在登录页面等待几秒待其初始化完成后即可使用。
 成功进入 Claude Code 对话框后，在对话框输入 /config 进入设置，勾选 Disable Login Prompt 配置来关闭登录页面。
